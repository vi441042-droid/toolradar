# ToolRadar

Статический русскоязычный каталог цифровых инструментов.

## Локальный просмотр
Откройте `index.html` в браузере. Сборка и серверная часть не требуются.

## Публикация
Загрузите содержимое папки в корень GitHub-репозитория, подключённого к Cloudflare Pages. Для обычного статического сайта команда сборки не нужна, директория публикации — `/`.

## Обновление каталога
В `index.html` найдите массив `tools` в блоке `<script>`. Для новой карточки добавьте объект с уникальным `id`, `name`, `category`, `description` и официальным `url`. Допустимые категории перечислены в массиве `categories`.

## Важно
Сайт не содержит рекламных скриптов, аналитики или партнёрских ссылок. Перед их подключением обновите раскрытие информации и политику конфиденциальности. Проверяйте тарифы и условия поставщиков по их официальным страницам.
