Инструменты: Разработка

Подборка инструментов категории Разработка: 12 сервисов с описаниями и официальными ссылками.

12 инструментов
  • GitHub — Платформа для хранения кода, совместной разработки и контроля версий.
  • Visual Studio Code — Редактор кода с расширениями для разных языков и задач.
  • Cursor — Редактор кода с функциями ИИ-помощи разработчику.
  • Replit — Онлайн-среда для написания, запуска и публикации приложений.
  • StackBlitz — Браузерная среда разработки веб-проектов.
  • CodePen — Площадка для экспериментов с HTML, CSS и JavaScript.
  • Postman — Инструменты для работы с API и тестирования запросов.
  • Docker — Платформа контейнеризации приложений.
  • Vercel — Платформа для развёртывания веб-приложений и сайтов.
  • Cloudflare — Сетевые, защитные и инфраструктурные сервисы для сайтов и приложений.
  • Supabase — Платформа backend-сервисов на базе PostgreSQL.
  • WordPress — Система управления содержимым для сайтов и блогов.

Как выбирать сервис

Сформулируйте задачу и сравните несколько продуктов на одинаковом сценарии. Перед регистрацией проверьте актуальные тарифы, ограничения бесплатного плана, экспорт данных, приватность и условия использования на официальном сайте.
