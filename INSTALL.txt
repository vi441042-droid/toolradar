TOOLRADAR SUPER UPDATE — INSTALLATION

1) Make a backup of the current GitHub repository.
2) Extract this ZIP.
3) Upload ALL files and folders from this ZIP into the ROOT of the repository (main branch).
4) Replace index.html, sitemap.xml and robots.txt when GitHub asks.
5) Keep any existing Google verification HTML file in the root. It is intentionally not replaced by this package.
6) Commit changes. Cloudflare Pages should deploy automatically.

This package includes:
- Updated Russian homepage with category navigation and English entry point.
- 7 Russian category pages.
- 4 original Russian practical guide articles + blog index.
- English landing page and 7 English category pages under /en/.
- Updated sitemap and robots.txt.

Important:
- English pages are intentionally a first content release, not a complete translation of every page.
- Sitemap contains static HTML URLs in this package. Submit https://toolradar-eqk.pages.dev/sitemap.xml in Search Console after deployment.
- Search indexing and traffic are not guaranteed; they depend on crawling, competition, content quality and time.
- No ad scripts or affiliate links are included. Add them only after approval/registration and disclose affiliate relationships clearly.
